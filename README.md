# Credit Risk Prediction Model 🏦

## Overview
An end-to-end machine learning solution that predicts loan default probability for banking risk assessment. Built using Python and Azure Machine Learning.

## Features
- 🤖 Random Forest classification model
- 📊 Exploratory Data Analysis with visualizations
- ⚖️ Fairness analysis across age groups using Fairlearn
- 🔍 Model explainability using SHAP values
- 📝 MLflow experiment tracking and model registry
- ☁️ Deployed on Azure Machine Learning workspace

## Tech Stack
- Python 3.11
- Scikit-learn
- MLflow
- Fairlearn
- SHAP
- Azure Machine Learning SDK v2
- Pandas, NumPy, Matplotlib, Seaborn

## Results
- Model Accuracy: 70%
- AUC-ROC Score: 0.53
- Fairness Analysis: Accuracy disparity of 9% across age groups
- Top Features: Credit Amount, Loan Duration, Age
